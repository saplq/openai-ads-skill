# Security

Security fixes are released on the latest tagged version.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/saplq/openai-ads-skill/security/advisories/new). Do not open a public issue for suspected credential, privacy, confirmation-replay, or API-routing problems.

Never include a real Ads API key, CAPI key, audience identifier, conversion payload, or private account data. Use synthetic reproduction data and describe the affected version and expected impact.
